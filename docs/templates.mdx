# Templates

Ready-made files to copy into a project. Every config on this page is the exact file described in the standards — copy it, do not retype it.

Each file is also served as a plain file, so a person or an AI agent can fetch it directly instead of copying from this page.

| File | Copy to | Plain file |
| --- | --- | --- |

## Agent skills {#skills}

**Copy to:** `.agents/skills/` in the project root, and again to `.claude/commands/` so Claude Code picks them up as slash commands.

The eight standard skills. Copy all of them into every project. See [Agent Skills](/Standards/agent-skills) for how they are written.

| Skill | Invocation | Plain file |
| --- | --- | --- |
| [Lint](#skill-lint) | `/lint [path]` | [`/templates/skills/lint.md`](pathname:///templates/skills/lint.md) |
| [Lint & fix](#skill-lintfix) | `/lintFix [path]` | [`/templates/skills/lintFix.md`](pathname:///templates/skills/lintFix.md) |
| [Format](#skill-format) | `/format [path]` | [`/templates/skills/format.md`](pathname:///templates/skills/format.md) |
| [Code review](#skill-codereview) | `/codeReview [branch, commit or path]` | [`/templates/skills/codeReview.md`](pathname:///templates/skills/codeReview.md) |
| [Update layout](#skill-updatelayout) | `/updateLayout` | [`/templates/skills/updateLayout.md`](pathname:///templates/skills/updateLayout.md) |
| [Security audit](#skill-securityaudit) | `/securityAudit [path]` | [`/templates/skills/securityAudit.md`](pathname:///templates/skills/securityAudit.md) |
| [TypeScript](#skill-typescript) | `/typescript [path]` | [`/templates/skills/typescript.md`](pathname:///templates/skills/typescript.md) |
| [Test](#skill-test) | `/test [path]` | [`/templates/skills/test.md`](pathname:///templates/skills/test.md) |

### Lint {#skill-lint}

Runs ESLint (and Stylelint if configured) in check-only mode; reports all issues grouped by file.

<CodeBlock language="markdown" title="lint.md">{skillLint}</CodeBlock>

### Lint & fix {#skill-lintfix}

Runs ESLint and Stylelint in fix mode, then Prettier; reports what changed and what is left.

<CodeBlock language="markdown" title="lintFix.md">{skillLintFix}</CodeBlock>

### Format {#skill-format}

Runs Prettier in write mode; reports reformatted files.

<CodeBlock language="markdown" title="format.md">{skillFormat}</CodeBlock>

### Code review {#skill-codereview}

Reviews changes for correctness, security, types, tests and standards compliance. Report only.

<CodeBlock language="markdown" title="codeReview.md">{skillCodeReview}</CodeBlock>

### Update layout {#skill-updatelayout}

Regenerates the "Repository layout" section of `AGENTS.md` (and "Workspace packages" in monorepos).

<CodeBlock language="markdown" title="updateLayout.md">{skillUpdateLayout}</CodeBlock>

### Security audit {#skill-securityaudit}

Audits dependencies and code for secrets, missing access control, unvalidated input and injection. Report only.

<CodeBlock language="markdown" title="securityAudit.md">{skillSecurityAudit}</CodeBlock>

### TypeScript {#skill-typescript}

Tightens loose types and removes `any`, `!` and unexplained `as`.

<CodeBlock language="markdown" title="typescript.md">{skillTypescript}</CodeBlock>

### Test {#skill-test}

Runs the test suite; reports failures grouped by cause, tests that never ran, and files missing a test.

<CodeBlock language="markdown" title="test.md">{skillTest}</CodeBlock>
